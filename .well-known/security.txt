  RFC 9116 security contact file.

  Expires is REQUIRED and must be a future RFC 3339 timestamp. Hardcoding a date
  means it silently expires and the file becomes invalid, so it is derived here
  from the build time plus one year: every deploy refreshes it. If the site is
  not rebuilt for a year it will still go stale, which is the one thing to watch.

  This directory starts with a dot, and Jekyll skips dotfiles by default, so
  `.well-known` must stay listed under `include:` in _config.yml or this file
  will never appear in _site.
{%- endcomment -%}
