{%- comment -%} Colour theme selector: Light, Dark, or System (follow the device setting). Included once, in the menu button row of header.html. Desktop: an icon button that opens a small panel. Mobile: the button is hidden and the same three options sit inline in the slide-in menu. The options are native radio buttons, so arrow keys, focus and screen-reader announcements come from the browser; assets/js/theme-switch.js only stores the choice and flips the data-theme attribute on . Without JavaScript the control is display:none (no dead button). With JavaScript its space is reserved from the first paint (the inline script in header.html sets data-theme-pref on ) and it is only made visible once the script is ready, so revealing it never moves the menu. Class names avoid the substring "bg-" on purpose (base.scss gives every [class*='bg-'] element position:relative and a background-size). {%- endcomment -%}
