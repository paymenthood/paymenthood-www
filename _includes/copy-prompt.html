{%- comment -%} Copy-to-clipboard buttons, and deep links into Bootstrap tabs. Behaviour ships with the markup, the same pattern as faq.html and page-nav-scrollspy.html, and is guarded by a window flag so a page that includes it twice binds once. COPY copies the textContent of #some-id. textContent rather than innerText so the copied text is the markup's text exactly, with no rendering-dependent line collapsing. navigator.clipboard needs a secure context. The fallback (a temporary readonly textarea and execCommand) covers the rest, and when both fail the text is selected so the visitor can press Ctrl+C: a copy button that fails silently is worse than none. The button announces the result through [data-copy-status], a polite live region, because swapping the label alone is invisible to a screen reader. MEASUREMENT Each successful copy pushes { event: 'ai_prompt_copied', ai_tool: } to dataLayer. dataLayer is created up front in header.html, so the push queues even before the container loads, and nothing personal is in it. Nothing consumes the event until a GTM trigger is created for it. DEEP LINKS Tabs are Bootstrap's own (data-bs-toggle="tab"). Bootstrap does not read the URL, so /page/#replit would open the first tab. Any trigger carrying data-tab-hash becomes addressable by that value, and the hash follows the active tab so the address bar is shareable. {%- endcomment -%}
