That is real differentiation but it is NOT a page — 40 pages built only from name substitution is precisely the "scaled content abuse" pattern Google penalises, and .docs/seo-content-plan.md §1 warns against it in this exact wording. So the publication gate here is stricter than the provider pages': a combo page needs BOTH a verified provider data file AND a combo file carrying `intro`, at least one `notes` entry, and `verified_by`. Until both hold, the template renders a review banner and the stub stays noindex. Fifteen genuinely useful combo pages beat forty templated ones.
