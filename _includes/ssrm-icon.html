{%- comment -%} Inline SVG icons for /trust-center/shared-responsibility/. Inline rather than an icon font: the page needs eleven glyphs and pulling a whole font file for eleven glyphs costs more than the markup does. Every path is 24x24, stroke-based, and inherits currentColor so the party and duty cards can recolour them from CSS. Usage: {% include ssrm-icon.html name="shield" %} {%- endcomment -%} {%- assign n = include.name -%}
