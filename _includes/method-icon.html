{%- comment -%} Inline SVG for a payment-method type. {% include method-icon.html key="qr" %} `key` comes from the `icon:` field on each entry in a provider data file's `methods:` list. Unknown or missing keys fall through to the card glyph, so a new provider never renders a hole. Icons are line-art on a 24x24 grid at stroke-width 2 to match every other SVG on the site, and inherit `currentColor` so the .method-icon colorways tint them. They are decorative — the method name is always adjacent in text — so each carries aria-hidden and no title. {%- endcomment -%} {%- assign k = include.key | default: 'card' -%}
