{%- comment -%} Click-to-load YouTube embed ("facade" pattern) plus VideoObject structured data. WHY IT IS NOT A PLAIN IFRAME: A normal YouTube iframe loads third-party scripts and storage the moment the page renders, which happens BEFORE the cookie banner is answered and would undo the consent gate in header.html. Here nothing is requested from YouTube until the visitor clicks play, and the click is itself the intent signal. It is also ~500 KB of JavaScript that never loads for the majority who do not watch. The poster is self-hosted for the same reason. The iframe uses youtube-nocookie.com and autoplay=1 (autoplay applies only after the click, never on page load). Parameters: id - (required) YouTube video id title - (required) video title; used as the button label and schema name poster - (required) site-relative path to the poster image description - (required) one-sentence description for the schema duration - (required) ISO 8601, e.g. PT1M27S upload_date - (required) FULL ISO 8601 timestamp WITH a timezone offset, e.g. 2026-08-04T13:00:05-07:00. A bare date (2026-08-04) is accepted by Google but raises "Datetime property uploadDate is missing a timezone" in the Rich Results Test, because it cannot tell which timezone midnight refers to. YouTube exposes the exact value: curl the watch page and grep for "uploadDate". eyebrow - small label above the heading (optional) heading - section heading (optional; omit to render the player alone) lead - paragraph under the heading (optional) bg - section background class (default: bg-light) {%- endcomment -%}
