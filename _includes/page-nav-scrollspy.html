{%- comment -%} Highlights the .page-nav link for whichever section is currently in view. Behaviour ships with the markup so any page that renders a .page-nav gets it, the same pattern faq.html uses. Guarded by a window flag so a page including it twice binds once. IntersectionObserver rather than a scroll handler: no layout thrash, and it is supported everywhere the rest of the site's JS already assumes. If the API is missing the nav still works — it is anchor links, the highlight is the only thing lost. {%- endcomment -%}
