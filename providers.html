{%- comment %} Rendered from _data/providers/*.yml, not hand-written. Before this the page carried 36 hardcoded cards while the data directory held its own list, so the two could drift apart silently — and adding a provider meant editing the card markup, `provider_count` in _config.yml and a data file, in three places. Now the data file is the only declaration: `status: live` is what puts a provider on this page and what allows its /providers// page to exist. Two Liquid constraints shape this loop. A `for` collection cannot contain a filter, so the category order is assigned first; and site.data.providers is a hash, so each `entry` is a [slug, data] pair and entry[1] is the record. Jekyll already yields data hashes in key order, which is why no sort is needed. {% endcomment -%} {%- assign groups = "global,regional,crypto" | split: "," -%}
