## About PaymentHood

[PaymentHood](https://www.paymenthood.com) is a payment orchestration platform that
connects your store to 30+ payment providers through a single free, open-source
plugin — with automatic routing, failover, webhook verification and server-side
confirmation handled for you.

- 🔌 **One integration, 30+ providers** — PayPal, Stripe, Adyen, Paystack, Razorpay, Binance Pay and more
- 🆓 **Free & open-source** — no per-transaction fee; you pay only your provider's processing fees
- 🔁 **Automatic routing & failover** — add or switch providers from a dashboard, no code changes
- 🧾 **Recurring / subscription billing** supported on WHMCS
- 🛡️ **Signed webhooks + server-side verification** built in
